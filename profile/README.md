# AI Craftbook

[AI Craftbook](https://aicraftbook.com/) is a reference site for putting AI to work: skills, MCP servers,
automations, model comparisons and step-by-step guides, each with its sources and the date we checked them.

## Open source

**[aicraftbook-skills](https://github.com/aicraftbook/aicraftbook-skills)**: original agent skills (SKILL.md
folders) for Claude Code and the Claude apps. Each one is tested against a no-skill baseline, security-scanned,
versioned and MIT licensed.

A few to start with:

- [MCP Mechanic](https://github.com/aicraftbook/aicraftbook-skills/tree/main/skills/mcp-mechanic): set up and fix MCP servers without exposing secrets.
- [Prompt Proof](https://github.com/aicraftbook/aicraftbook-skills/tree/main/skills/prompt-proof): find weak spots in a prompt and write tests for it.
- [Cost Compass](https://github.com/aicraftbook/aicraftbook-skills/tree/main/skills/cost-compass): estimate what an AI feature or automation will cost to run.

Full guides, test results and security reviews: [aicraftbook.com/skills](https://aicraftbook.com/skills).
Want to help? Read the [contributing guide](https://github.com/aicraftbook/aicraftbook-skills/blob/main/CONTRIBUTING.md).
